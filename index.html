建模学习

从关节变量到末端位姿

正向运动学利用已知机构参数和关节变量，求工具相对基座的位姿。本例应计算到H点，不能停在第三关节J₃。

先明确坐标系

基座系{0}固定于O，x₀向右、y₀向上、z₀垂直纸面向外。{1}、{2}、{3}的原点分别位于O、J₂、J₃，x轴分别沿第一、第二、第三杆，z轴均垂直纸面向外，y轴按右手规则确定。工具系{H}原点位于H，方向与{3}相同。

改进型D-H变换

采用列向量。Aᵢ=ⁱ⁻¹Tᵢ，把第i系中的点坐标变换到第i−1系：

Aᵢ = Rₓ(αᵢ₋₁) Tₓ(aᵢ₋₁) R𝓏(θᵢ) T𝓏(dᵢ)

同一z轴的旋转与平移可交换，其他变换不能随意交换。标准型和改进型D-H的建系及参数表不能混用。

第三关节到H的50 mm刚性段在此建模为固定工具偏移，不是在第三杆之外再增加50 mm：

⁰Tₕ = A₁ A₂ A₃ Tₓ(50)

用几何投影理解结果

三杆相对基座+x方向的角度依次为θ₁、θ₁+θ₂、θ₁+θ₂+θ₃。

x = 100cosθ₁ + 100cos(θ₁+θ₂) + 50cos(θ₁+θ₂+θ₃)
y = 100sinθ₁ + 100sin(θ₁+θ₂) + 50sin(θ₁+θ₂+θ₃)
φ = θ₁+θ₂+θ₃

计算器采用角度制。工具朝向按360°周期等价，但实际关节转数及限位不能忽略。以上位置公式只适用于本页明确规定的平面模型。

完整例题：姿态A

θ₁=0°，θ₂=90°，θ₃=−90°。三杆绝对方向角为0°、90°、0°。

x=100+0+50=150 mm
y=0+100+0=100 mm
φ=0°

第三关节J₃=(100,100) mm，工具H=(150,100) mm。

⁰Tₕ = [1 0 0 150
       0 1 0 100
       0 0 1   0
       0 0 0   1]

位置列单位为mm，旋转块无量纲。点击“姿态A”将计算结果与几何形状互相核对。

计算核验

沿用以上模型，令θ₁=90°、θ₂=−90°、θ₃=0°，求工具H的位置与朝向。请先计算再检查。

方法提示先累加得到各杆相对基座的方向角，再求投影；最后一段50 mm也要计入。
完成后查看解析方向角依次为90°、0°、0°。x=0+100+50=150 mm，y=100+0+0=100 mm，φ=0°。这与姿态A的末端位姿相同，但肘部形状不同，说明逆向问题可能存在多解，并非每个目标都一定多解。

交流反思

主题讨论：某同学说：“末端坐标算对了，机械臂就可以直接运行。”你同意吗？指出还应检查的一项条件并说明原因，2—3句话即可。

讨论后查看参考思路正向运动学只给出理想模型下的几何位姿。还需检查关节限位、碰撞、基座与工具标定或运动跟踪等实际条件。例如目标坐标正确，运动过程仍可能碰到工装。认真核验、尊重证据、如实说明验证范围，是工程实践中的责任。

三个检查习惯

  1. 角度相对谁定义？
  2. 算到了关节、机械接口还是工具参考点？
  3. 几何形状与计算是否一致，结论的适用范围是什么？
